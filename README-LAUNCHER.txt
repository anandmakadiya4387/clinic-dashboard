ONE-CLICK LAUNCHER

Office: double-click Office.exe
Reception: double-click Reception.exe

Do not double-click office.html/reception.html.
Do not run Build-EXE.bat; it is not included in this version.

On first launch, the EXE downloads the official Python 3.13.13 Windows embedded runtime if runtime\python.exe is not present. Internet is required only for this first runtime setup. After that, the application can run offline.

Keep the complete folder together so the SQLite database, backups, runtime and logs remain with the application.
